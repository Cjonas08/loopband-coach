Hoe krijg ik een Client ID en Secret? (eenmalig per persoon)
  1. Log in op Strava met het account van die persoon en ga naar strava.com/settings/api.
  2. Maak een applicatie: naam bv. "Loopband Coach", categorie "Training", website mag iets willekeurigs zijn.
  3. Bij Authorization Callback Domain vul je in: localhost
  4. Kopieer Client ID en Client Secret hierboven bij de juiste persoon en klik Koppel met Strava.

De gegevens blijven alleen in deze browser. Op een ander toestel (gsm/tablet) moet je één keer opnieuw koppelen.

Over

Stuurt de loopband aan via het standaard Bluetooth FTMS-protocol (Fitness Machine Service), hetzelfde dat Zwift en Kinomap gebruiken. Werkt in Chrome of Edge op Windows, Android en ChromeOS. Op iPhone/iPad werkt Web Bluetooth niet in Safari — gebruik daar de Bluefy-browser. Blijf altijd zelf alert: de noodstop van de loopband blijft leidend.
