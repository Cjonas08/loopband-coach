# Loopband Coach

Webapp om gestructureerde looptrainingen uit te voeren op een Bluetooth FTMS-loopband (getest met VirtuFit Elite Comfort).

- Trainingen maken via tekst, ingesproken instructies of import (.zwo / .json)
- Stuurt snelheid en helling per stap via Web Bluetooth (FTMS)
- Export naar TCX en upload naar Strava

Werkt in Chrome/Edge op Windows en Android (https of localhost vereist voor Bluetooth).
Gebruik: open https://cjonas08.github.io/loopband-coach/
